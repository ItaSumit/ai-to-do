# Todo App

A simple to-do list application for **Claude Code Lab 101**.

> **Heads up:** this lab ships with three intentional bugs. Your task is to find and fix them with Claude Code's help. The product spec at `spec.md` describes the correct behavior; the source code deliberately does not match it in three places.

## Quick Start

```bash
npm install
npm start
```

Open http://localhost:3000 in your browser.

## Running Tests

```bash
npm test
```

Tests require the server to be running on port 3000.

## Tech Stack

- **Backend:** Node.js + Express
- **Frontend:** Vanilla HTML/CSS/JavaScript
- **Tests:** Node.js built-in test runner
